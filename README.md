# ☀️ SunEssentials  
**Your One-Stop Modern Summer eCommerce Destination**  

## 📋 Purpose  
**SunEssentials** is a modern, high-performance eCommerce platform designed specifically for seasonal summer products. From high-end sunglasses to skincare and trendy outfits, the platform provides a seamless shopping experience. It focuses on a vibrant "Sunny" aesthetic, robust authentication, and a responsive user interface.

## 🚀 Live URL  
Check out the live project here: [SunEssentials](https://summer-essentials-store-red.vercel.app/)

---

## ✨ Key Features   
*   **Secure Authentication:** Powered by **BetterAuth**, supporting both Email/Password and Google Social Login.    
*   **Protected Routes:** Private pages for authenticated users to manage profile and view product details.
*   **Update Information Feature:** Allows users to update display name and profile picture.
